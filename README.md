# Vendedor IA TikTok V2
1. Instale Node.js 18+.
2. Rode `npm install`.
3. Copie `.env.example` para `.env`.
4. Coloque sua chave em `OPENAI_API_KEY` no `.env`. Nunca coloque a chave no HTML nem publique o `.env`.
5. Rode `npm start`.
6. Abra `http://localhost:3000`.

O botão gera um roteiro com IA. A próxima etapa pode adicionar narração e vídeo.
